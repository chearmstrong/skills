# Resources

References for installing, authoring and checking skills across coding agents.
See [Working Style](working-style.md) for my workflow and companion skills.

## Start Here

- [Agent Skills specification](https://agentskills.io/specification) — the portable format, metadata and resource structure.
- [Skills CLI](https://www.skills.sh/docs/cli) — install and manage skills across supported agents.
- [Install Skills](install.md) — the recommended installation route for this repository.

## Authoring And Evaluation

These are vendor guides, rather than portable format requirements.

- [Skill authoring best practices](https://platform.claude.com/docs/en/agents-and-tools/agent-skills/best-practices) — concise instructions, progressive disclosure and evaluation during development.
- [Demystifying evals for AI agents](https://www.anthropic.com/research/demystifying-evals-for-ai-agents) — representative tasks, grading and evidence of actual behaviour.

## Codex And OpenAI Plugins

This repository recommends direct skill installation and does not provide a
Codex plugin bundle. The plugin links below are optional platform background.

- [Build skills](https://learn.chatgpt.com/docs/build-skills) — OpenAI guidance on creating reusable skills.
- [Custom instructions with AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md) — project and personal instructions.
- [Plugins](https://learn.chatgpt.com/docs/plugins) — using plugins in ChatGPT and Codex.
- [Package your plugin](https://developers.openai.com/plugins/build/plugins) — packaging skills and other resources for distribution.
